一、项目使用说明：
1、安装docker
2、执行docker compose up -d安装依赖服务
3、将mysql连接字符串放在appsettings.json的connstr
4、将redis的连接字符串放到appsettings.json的redisconn
5、将rabbitmq的连接字符串放到appsettings.json的event_bus_conn
6、修改appsettings.json的General=》url域名


二、国内centos安装docker
# 步骤1： 获取 docker-ce 软件源的 yum repo
sudo yum install -y yum-utils device-mapper-persistent-data lvm2 
sudo yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

# 步骤2：安装Docker
sudo yum install -y docker-ce docker-ce-cli containerd.io

# 步骤3：启动 docker 并设置开机启动
sudo systemctl start docker
sudo systemctl enable docker

# 步骤4：设置docker国内镜像
编辑/etc/docker/daemon.json（没有则创建）
添加如下内容：
{  
  "registry-mirrors": [  
    "https://docker.xuanyuan.me",
        "https://docker.m.daocloud.io",
        "https://docker.imgdb.de",
        "https://docker-0.unsee.tech",
        "https://docker.hlmirror.com"
  ]  
}

五、模块开发说明：
1、每个模块要求在Modules里有个单独文件夹。
2、需要启用的模块需要在App入口项目的services.txt注册（添加模块名称）。
3、可以在App入口项目引用每个模块，这样编译后每个模块会自动生成到项目下面。
4、每个模块下面需要创建个PluginConfig.cs文件，模块启动时会初始化执行该文件。
5、需要定时器处理的模块，要在Configure方法上加上plg.RegisterQuartzTask();


六、模块间通信说明：
注：模块间除非是上下级关系，否则不可以直接调用。应该通过以下方式调用：
1、通过在PluginConfig里调用RegisterCall、RegisterBus注册监听其它模块触发的事件或向其它模块返回信息。
2、RegisterCall可以返回信息给其它模块，但只能一个模块处理一种事件。
3、RegisterBus可以多个模块处理同一种事件。
4、使用BusUtility.Call或BusUtility.Dispatch调用其它模块的监听。
