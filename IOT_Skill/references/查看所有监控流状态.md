# 查看所有监控流状态的接口介绍与示例
## 接口介绍
1. 请求参数：无参数

2. 返回的data类型为数组，数组的元素定义如下

| 字段名 | 类型 | 说明 |
|--------|------|------|
| stream_id | String | 流Id |
| is_running | Boolean | 是否监控中 |
| has_frame | Boolean | 是否存在最新画面 |
| error | String | 监控中的错误信息 |


## 操作示例

GET 请求
```bash
curl http://127.0.0.1:8111/api/list-monitor
```


响应示例：
```json
{
  "code": 0,
  "message": "",
  "data": [{"stream_id":"camera1","is_running":true,"has_frame":true,"error":""}]
}
```
