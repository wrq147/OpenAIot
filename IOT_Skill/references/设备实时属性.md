# 设备实时属性的接口介绍与示例
## 接口介绍
1. 请求参数：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | String | 通讯Id |
| needSend | Boolean | 是否获取实时的属性数据 |

2. 返回的data类型为数组，数组的元素定义如下

| 字段名 | 类型 | 说明 |
|--------|------|------|
| Name | String | 属性名称 |
| Code | String | 属性标识符 |
| OptionType | String | 数据类型 |
| Value | 任意类型 | 属性值，类型由OptionType定义 |
| Unit | String | 显示单位 |
| UpdatedOn | String | 更新时间 |
| Description | String | 属性描述 |


OptionType说明：
int表示整型
float表示浮点型
string表示字符串
date表示日期，是Number类型时间戳，例如1638331860000
boolean表示布尔型，true或false
enum表示枚举，是String类型的字符串


## 操作示例

GET 请求
```bash
curl http://127.0.0.1:880/IoTRulesService/HttpRule/Live?id=dtu323&needSend=true
```

响应示例：
```json
{
  "code": 0,
  "message": "",
  "data": [{
    "Name": "信号强度",
    "Code": "signal",
    "OptionType": "float",
    "Value": 95.0,
    "Unit": "dBm",
    "UpdatedOn": "2026-03-19 10:00:00",
    "Description": "设备的4g信号强度"
  }]
}
```
