# 我的所有设备的接口介绍与示例
## 接口介绍
1. 请求参数：无参数
2. 返回的data类型为数组，数组的元素定义如下

| 字段名 | 类型 | 说明 |
|--------|------|------|
| Name | String | 设备名称 |
| DeviceNumber | String | 设备编码 |
| DeviceId | String | 通讯Id |
| ProtocolId | String | 设备协议Id |
| ProductName | String | 设备所属产品名称 |
| Online | Number | 在线状态（0=离线，1=在线，2=未初始化） |
| Lng | Number | 经度 |
| Lat | Number | 纬度 |
| AreaCode | String | 所在区域代码 |
| RoomName | String | 设备所在房间 |
| IsVideo | Boolean | 是否为视频监控设备 |
| Funs | Array | 设备的功能定义 |
| Props | Array | 设备的实时属性定义 |

Funs的元素定义如下
| 字段名 | 类型 | 说明 |
|--------|------|------|
| name | String | 功能名称 |
| code | String | 功能标识符 |
| description | String | 功能描述 |
| inputs | Array | 功能输入参数 |

inputs的元素定义如下
| 字段名 | 类型 | 说明 |
|--------|------|------|
| name | String | 参数名称 |
| code | String | 参数标识符 |
| type | String | 参数数据类型，int、float、string、date、boolean、enum |
| remark | String | 参数备注 |
| elements | 键值对 | 枚举元素 |

inputs的type数据类型说明：
int表示整型
float表示浮点型
string表示字符串
date表示日期，是Number类型时间戳，例如1638331860000
boolean表示布尔型，true或false
enum表示枚举，必需从elements里选择值，elements里键和值都是字符串，也就是说enum类型的参数应该传elements里的值字符串

Props的元素定义如下
| 字段名 | 类型 | 说明 |
|--------|------|------|
| name | String | 属性名称 |
| code | String | 属性标识符 |
| type | String | 数据类型 |
| description | String | 属性描述 |

Props的type数据类型说明：
int表示整型
float表示浮点型
string表示字符串
date表示日期，是Number类型时间戳，例如1638331860000
boolean表示布尔型，true或false
enum表示枚举，是String类型的字符串
