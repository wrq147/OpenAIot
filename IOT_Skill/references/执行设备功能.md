# 我的所有设备的接口介绍与示例
## 接口介绍
1. 请求参数：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| Number | String | 设备编码 |
| FunctionId | String | 功能标识符 |
| Inputs | 键值对 | 功能输入参数 |

Inputs的键和值由'我的所有设备接口'的Funs的功能输入参数定义

2. 返回的data类型为键值对，如无特殊需求可忽略


## 操作示例

POST 请求
```bash
curl -X POST http://127.0.0.1:8111/api/start-monitor \
-H "Content-Type: application/json"  -H "token: 123456789" \
-d '{"Number":"a12345","FunctionId":"ptz","Inputs":{"angle":1.0}}'
```

响应示例：
```json
{
  "code": 0,
  "message": "",
  "data": {
    "测试1":0,
    "测试2":"无用"
  }
}
```
