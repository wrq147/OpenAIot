# 停止监控的接口介绍与示例
## 接口介绍
1. 请求参数：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| stream_id | String | 流Id |


2. 返回的data为空字符串，可忽略


## 操作示例

POST 请求
```bash
curl -X POST http://127.0.0.1:8111/api/stop_monitor \
-H "Content-Type: application/json" \
-d '{"stream_id":"camera1"}'
```

响应示例：
```json
{
  "code": 0,
  "message": "",
  "data": ""
}
```
