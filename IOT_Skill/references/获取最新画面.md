# 获取最新画面的接口介绍与示例
## 接口介绍
1. 请求参数：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| stream_id | String | 流Id |


2. 返回的data为base64字符串格式的图片


## 操作示例

POST 请求
```bash
curl -X POST http://127.0.0.1:8111/api/get_frame \
-H "Content-Type: application/json" \
-d '{"stream_id":"camera1"}'
```

响应示例：
```json
{
  "code": 0,
  "message": "",
  "data": "data:image/jpeg;base64,/9j/4QAwRXhpZgAATU0AKgAAAAgAAQExAAIAAAAOAAAAGgA"
}
```
