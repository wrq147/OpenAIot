# Security Policy

## Supported Versions
Only the latest main branch release receives security fixes.
Older versions are not maintained.

## Report Vulnerabilities
Do NOT open public GitHub issues for security bugs.
Please use GitHub's private vulnerability report tool:
Repo → Security → Report a vulnerability

### Response Timeline
- Acknowledge receipt within 5 business days
- Fix will be released in next minor version
- Reporter will be credited in release notes

## Security Rules
1. Never commit API keys, passwords, private tokens
2. Sanitize all user input to prevent injection attacks
3. Keep all dependencies updated
